    Community sharing

    To see and share catches with other anglers, connect a free Firebase project (one-time setup, a few minutes):
    1. Go to console.firebase.google.com → Add project.
    2. Build → Firestore Database → Create database (start in test mode is fine to begin).
    3. Build → Authentication → Sign-in method → enable "Anonymous."
    4. Project settings → your apps → Web app (</>) → copy the firebaseConfig object.
    Paste that whole config object below.
